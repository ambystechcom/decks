<Notes>
- The emitters encode the gotchas: Claude Code does not read AGENTS.md, so it gets a CLAUDE.md bridge. Copilot CLI has no prompt files, so phases become skills. MCP top-level keys differ per tool.
- Six families, ten targets, because the CLI and IDE flavours of some tools differ.
- `ambykit sync` re-emits everything from the neutral source. Edit once, sync, every assistant is current.
